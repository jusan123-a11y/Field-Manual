# Field Manual — Practical IT Guides

A responsive, high-performance landing page and digital storefront for **Field Manual: Practical IT Guides**, faithfully crafted from the original editorial design mockup.

---

## Features

- **Pixel-Accurate Visual Design**:
  - Warm ivory paper tone (`#F8F6F0`) and parchment card backgrounds matching the design aesthetic.
  - Editorial serif typography paired with clean, legible technical sans-serif text.
  - Realistic 3D book mockup display with spine depth, perspective tilts, and dynamic shadow.
  - Crisp high-resolution photography and vector SVG line-art icons.

- **Interactive E-Commerce & Utilities**:
  - **Slide-Out Cart Drawer**: Add guides, change quantities, remove items, live cart count badge, and promo codes (`FIELD10` for 10% off).
  - **Simulated Checkout & Instant Download**: Digital delivery confirmation modal with download actions.
  - **Interactive 3-Question Diagnostic Quiz**: "Not sure which guide you need?" quiz wizard diagnosing role, urgency, and depth to recommend the exact manual.
  - **Look Inside / Preview Modal**: Live chapter sample excerpt, full table of contents, and field response quickcards.
  - **Dynamic Filtering**: Filter library guides by Category (*All*, *Practical*, *Field*, *Starter*), by Target Role (e.g. *Small Business*, *Junior IT*, *Security Installers*), or by Problem area (*Wi-Fi*, *Printers*, *Computers*, *Networks*, *Cameras*, *Cybersecurity*).
  - **Instant Search Palette**: Fast live search across all manuals and topics (`Ctrl+K` or `/` shortcut).
  - **Free Community Field Notes**: Instant download modal for quick reference sheets and cheat sheets.
  - **IT Toolkit Bundles**: Bundle modal for the Complete All-in-One Field Pack and Specialist Packs.
  - **Mobile Responsive**: Custom hamburger menu and slide-in drawer optimized for smartphones and tablets.

---

## Quick Start

You can open and view the website in two simple ways:

### Option 1: Direct File Opening
Double-click `index.html` or open it in any browser (Chrome, Edge, Safari, Firefox). Zero build tools required.

### Option 2: Local Development Server
Run the included zero-dependency Node server:
```bash
node server.js
```
Then visit:
```
http://localhost:3000
```
