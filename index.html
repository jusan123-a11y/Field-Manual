Chapter 3: The 4-Step Internet Diagnostic Tree

When an office worker shouts "the internet is down," never touch the router first. Follow the ladder:

Step 1: Ping the Loopback Address
ping 127.0.0.1
If this fails, the local TCP/IP stack is damaged. No router reboot will fix this.
Step 2: Ping the Default Gateway
ping 192.168.1.1 (or your gateway IP from ipconfig)
If this responds with 0% packet loss, the physical and Wi-Fi link to your router is 100% operational.
Step 3: Ping Public DNS by IP
ping 1.1.1.1
If this works but websites don't load, you have a pure DNS lookup failure, not an internet outage.

Emergency Response Quickcard

  • ✓ Check physical link lights: Amber = 100Mbps, Green = 1Gbps.
  • ✓ Verify IP assignment: If address starts with 169.254.x.x, DHCP has failed.
  • ✓ Flush DNS cache: ipconfig /flushdns before testing domain names.
  • ✓ Test DNS resolver: nslookup google.com 8.8.8.8 to isolate ISP provider issues.
